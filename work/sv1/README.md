# SV1 — Dân (Nhóm trưởng / Requirement / Báo cáo)

## Nhiệm vụ

- Đọc và tóm tắt yêu cầu Đồ án 2
- Lập kế hoạch 1 tháng (tuần 1 → tuần 4)
- Phân công công việc cho 5 thành viên
- Tạo và quản lý issue trên Redmine
- Tổng hợp Weekly Report mỗi tuần
- Viết báo cáo cuối kỳ + slide thuyết trình
